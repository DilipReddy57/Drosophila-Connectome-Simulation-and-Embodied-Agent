# C2 Graph Analytics and Sanity Validation

This directory contains the machine-readable payloads, metric registries, and human-readable reports generated by the C2 validation stage.

## Pinned C1 Inputs
- C1 Merge Commit: `93603efdf845f691e581f1771af3630c3bb72218`
- Dataset: FAFB v783 (adult female brain)
- Inputs: `data/derived/final_v1/*.parquet`

## Agent Responsibilities
- **A. Data Integrity:** Endpoint existence, mapping bijective nature, zero-indexed contiguity, duplicate rows.
- **B. Degree distributions:** Count and synapse-weighted in/out degree per node.
- **C. Graph topology:** Weak/strong components, graph density, reciprocity.
- **D. Region analysis:** Connection and synapse distributions across source `neuropil` regions.
- **E. Neurotransmitter:** `source_nt_type` distributions, accounting for `.first()` mapping.
- **F. Cell type:** Distributions and missing-annotation coverage based on `consolidated_cell_types.csv.gz`.
- **G. Literature benchmark:** Evidence tracking from external sources for final validation.
- **H. Independent Auditor:** Reconcile invariants, e.g. `sum(out_degree) == E`, and challenge agent math.
